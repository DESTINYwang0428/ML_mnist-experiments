## 📊 最常用的 5 个优化器

| 优化器 | 一句话特点 | 适用场景 |
|--------|-----------|----------|
| **SGD** | 最基础的梯度下降，简单 | 小数据集、调试、想从零理解原理 |
| **SGD + Momentum** | SGD 加动量，加速收敛 | 比 SGD 快，适合中等规模任务 |
| **Adam** | 自适应学习率 + 动量，目前最主流 | **绝大多数场景的首选** ✅ |
| **RMSprop** | 自适应学习率，专治梯度震荡 | RNN、强化学习 |
| **AdamW** | Adam 的改进版（修正了权重衰减） | Transformer、大模型（GPT、ViT） |

---

## 🔍 逐个拆解

### 1. SGD（随机梯度下降）

```python
optimizer = optim.SGD(model.parameters(), lr=0.01)
```

| 属性 | 说明 |
|------|------|
| 原理 | 每次沿着梯度的反方向走一小步 |
| 优点 | 简单、容易理解 |
| 缺点 | 收敛慢、容易卡在局部最优 |
| 适用 | 小数据集、教学演示、想从零理解梯度下降 |

**一句话：** 最基础的“下坡走路”，每一步都按当前坡度走，但容易走弯路。

---

### 2. SGD + Momentum（带动量的 SGD）

```python
optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
```

| 属性 | 说明 |
|------|------|
| 原理 | 保留上一次的更新方向，像“滚雪球”一样加速 |
| 优点 | 比 SGD 收敛快，能冲出小坑 |
| 缺点 | 仍需手动调学习率 |
| 适用 | 中等规模任务、图像分类 |

**一句话：** 下坡时带点“惯性”，不容易卡在小坑里。

---

### 3. Adam

```python
optimizer = optim.Adam(model.parameters(), lr=0.001)
```

| 属性 | 说明 |
|------|------|
| 原理 | 每个参数有自己的学习率 + 动量，自动适应 |
| 优点 | 收敛快、稳定、几乎不用调参 |
| 缺点 | 内存占用稍大 |
| 适用 | **绝大多数任务的首选** ✅ |

**一句话：** 自适应版本，每个参数有自己的步长，几乎不用调参，上手就能用。

---

### 4. RMSprop

```python
optimizer = optim.RMSprop(model.parameters(), lr=0.001)
```

| 属性 | 说明 |
|------|------|
| 原理 | 自适应学习率，抑制梯度震荡 |
| 优点 | 适合梯度变化剧烈的场景 |
| 缺点 | 不如 Adam 通用 |
| 适用 | RNN（循环神经网络）、强化学习 |

**一句话：** Adam 的前身，专治梯度震荡，现在多用于 RNN。

---

### 5. AdamW（Adam 的改进版）

```python
optimizer = optim.AdamW(model.parameters(), lr=0.001, weight_decay=0.01)
```

| 属性 | 说明 |
|------|------|
| 原理 | Adam + 正确的权重衰减（L2 正则化） |
| 优点 | 比 Adam 泛化能力更强 |
| 缺点 | 多一个参数要调 |
| 适用 | Transformer、大语言模型、ViT（视觉 Transformer） |

**一句话：** Adam 的修正版，现在大模型都在用 AdamW，而不是 Adam。

## 🎯 怎么选？一张图搞定

```
你的任务是什么？
│
├── 刚入门、想跑通代码 → Adam ✅（容错率高，不用调参）
│
├── 小数据集、想理解原理 → SGD（简单直观）
│
├── 图像分类（CNN） → Adam 或 SGD + Momentum
│
├── RNN / LSTM → RMSprop 或 Adam
│
└── Transformer / 大模型 → AdamW（现在的主流）
```

---

## 💡 为什么现在用 Adam？

| 原因 | 说明 |
|------|------|
| 不需要调参 | 默认 `lr=0.001` 就能工作，对新手友好 |
| 收敛快 | 比 SGD 快好几倍，几轮就能看到效果 |
| 稳定 | 不会像 SGD 那样 loss 乱跳 |
| 主流 | 99% 的开源代码都用 Adam 或 AdamW |

---

### 📊 最常用的 5 个损失函数

| 损失函数 | 中文名 | 适用场景 | 一句话解释 |
|----------|--------|----------|-----------|
| **CrossEntropyLoss** | 交叉熵损失 | **多分类**（如 MNIST 10 个数字） | 模型输出各类概率，让正确类别的概率最大化 |
| **BCELoss / BCEWithLogitsLoss** | 二分类交叉熵 | **二分类**（如是/不是垃圾邮件） | 只判断两个类别（0 或 1） |
| **MSELoss** | 均方误差损失 | **回归问题**（如预测房价、温度） | 计算预测值和真实值的平方差 |
| **L1Loss** | 平均绝对误差 | **回归问题**（对异常值更鲁棒） | 计算预测值和真实值的绝对差 |
| **NLLLoss** | 负对数似然损失 | **多分类**（配合 LogSoftmax 使用） | CrossEntropyLoss 的“拆开版” |

---

### 🔍 逐个拆解（你只需要记住这些）

#### 1. CrossEntropyLoss（你正在用的）

```python
criterion = nn.CrossEntropyLoss()
```

| 属性 | 说明 |
|------|------|
| 适用 | 多分类（3 个类别以上） |
| 输入 | 模型的原始分数（logits），**不需要**自己手动加 Softmax |
| 特点 | 内部自动做了 Softmax + 对数 + 负对数，一步到位 |
| 你的场景 | MNIST 10 个数字分类 → ✅ 完美匹配 |

---

#### 2. BCELoss / BCEWithLogitsLoss（二分类）

```python
# 推荐用这个（内部自带 Sigmoid，数值更稳定）
criterion = nn.BCEWithLogitsLoss()

# 或者手动加 Sigmoid 后算 BCELoss（不推荐，容易数值溢出）
criterion = nn.BCELoss()
```

| 属性 | 说明 |
|------|------|
| 适用 | 二分类（是/否，有/无） |
| 输入 | 模型输出一个分数，`BCEWithLogitsLoss` 内部自动做 Sigmoid |
| 输出 | 一个概率值（0~1），判断属于正类的概率 |
| 场景 | 垃圾邮件检测、疾病预测、点击率预估 |

**例子：** 判断一张图片是不是猫 → 输出一个 0~1 的概率。

---

#### 3. MSELoss（回归问题）

```python
criterion = nn.MSELoss()
```

| 属性 | 说明 |
|------|------|
| 适用 | 回归问题（预测连续数值） |
| 输入 | 模型的预测值（任意实数） |
| 输出 | 预测值和真实值的**平方差** |
| 场景 | 房价预测、温度预测、股票价格预测 |

**例子：** 预测房子价格是 350 万，真实是 320 万 → 误差 30 万，平方后是 900 亿（很大，所以回归问题需要小心处理）。

---

#### 4. L1Loss（回归问题，对异常值不敏感）

```python
criterion = nn.L1Loss()
```

| 属性 | 说明 |
|------|------|
| 适用 | 回归问题 |
| 输入 | 模型的预测值 |
| 输出 | 预测值和真实值的**绝对差** |
| 场景 | 当数据中有很多异常值（离群点）时，L1 比 MSE 更鲁棒 |

**对比：**
- MSE：误差放大（平方），异常值影响很大
- L1：误差线性，异常值影响相对小

---

#### 5. NLLLoss（CrossEntropyLoss 的“拆开版”）

```python
# 需要自己手动加 LogSoftmax
log_probs = F.log_softmax(outputs, dim=1)
loss = nn.NLLLoss()(log_probs, labels)
```

| 属性 | 说明 |
|------|------|
| 适用 | 多分类 |
| 特点 | CrossEntropyLoss = LogSoftmax + NLLLoss |
| 场景 | 当你需要手动控制 Softmax 之前/之后的处理时使用 |

**你不需要用这个，直接用 CrossEntropyLoss 就够了。**

---

### 🎯 怎么选？一张图搞定

```
你的任务是分类还是回归？
│
├── 分类
│   │
│   ├── 二分类（是/否）→ BCEWithLogitsLoss
│   │
│   └── 多分类（3类以上）→ CrossEntropyLoss
│
└── 回归（预测数值）
    │
    ├── 数据干净、没有太多异常值 → MSELoss
    │
    └── 数据有异常值、希望更鲁棒 → L1Loss
```
